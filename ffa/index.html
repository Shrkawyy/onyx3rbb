JaxxV6

The custom client, loaded on Senpa's official web origin.

Install Tampermonkey script
  1. Install the Tampermonkey browser extension.
  2. Click the install button above and confirm the script.
  3. Open senpa.io/web/.
Do not open client.html directly. The userscript must run it on senpa.io so the game server sees Senpa's official browser origin and your normal connection.

JaxxV6 uses a direct WebSocket connection. GitHub Pages only hosts the static client files.
